# Fidelity National Information Services (fidelity-national-information)

Fidelity National Information Services (FIS) is a Fortune 500 global provider
of financial services technology offering solutions across retail and
institutional banking, payments, asset and wealth management, risk and
compliance, and outsourcing. FIS exposes APIs to financial institutions,
fintechs, and corporates through its Code Connect API marketplace. This
repository captures the APIs, developer tools, and machine-readable API
artifacts for FIS.
